#  MARSNOVA
### AI-Powered Mars Surface Suitability Prediction Using GIS & Machine Learning

## 🌌 About the Project
MARSNOVA is a space-tech project that aims to analyse the surface conditions of Mars using Geographic Information Systems (GIS) and Machine Learning.

The proposed system will accept latitude and longitude coordinates, extract relevant planetary surface data, and estimate a suitability score to support preliminary Mars exploration and location assessment.

## 🎯 Objectives
- Analyse selected locations on Mars using planetary datasets.
- Extract elevation and thermal-related surface parameters.
- Apply Machine Learning for surface-suitability estimation.
- Present location-based results through a user-friendly web interface.
- Support preliminary research for Mars exploration and landing-site assessment.

## ⚙️ Proposed Tech Stack
- **Language:** Python
- **GIS & Raster Processing:** Rasterio, GDAL, GeoTIFF
- **Data Processing:** NumPy, Pandas
- **Machine Learning:** Scikit-learn, Random Forest Regressor
- **Backend:** Flask
- **Frontend:** HTML, CSS, JavaScript
- **Data Sources:** NASA Planetary Data System (PDS)

## 🔄 Proposed Workflow
1. Enter Mars latitude and longitude.
2. Retrieve relevant values from planetary raster datasets.
3. Process and align the extracted data.
4. Analyse the parameters using a Machine Learning model.
5. Display an estimated surface-suitability score between 0 and 100.

## 🪐 Potential Applications
- Preliminary Mars landing-site assessment
- Comparison of Martian surface locations
- Planetary science research and education
- Data-driven Mars exploration planning

## 💡 Expected Outcome
A web-based prototype that combines GIS and Machine Learning to evaluate and visualize surface-suitability estimates for selected locations on Mars.

## ⚠️ Limitations
The reliability of the prediction depends on dataset quality, feature selection, and the availability of reliable training labels or validated scoring criteria. The system is intended for preliminary analysis and is not a certified landing-site selection tool.
